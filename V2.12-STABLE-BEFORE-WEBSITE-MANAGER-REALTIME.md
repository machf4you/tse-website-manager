## 1. Scope and Purpose

This is the **last confirmed stable restore point** of the TSE Website Manager prior to introducing the **Supabase Realtime Broadcast multi-user synchronization layer**.

## 2. Architectural Baseline

- **Authoritative Single Source of Truth**:
  - Backend SQLite Database (`website_manager.db`) served via Express API (`website-manager-api` on port 3005).
  - All CRUD mutations (`/api/websites`, `/api/websites/:id/package`, `/api/websites/:id/page-configs`, `/api/websites/:id/audits`, `/api/websites/:id/link-recommendations`) persist directly to SQLite WAL tables.
- **Client State**:
  - React SPA with full client-side routing and views (`WebsitesDashboard`, `ManageWebsitePage`, `PageManagementPage`, `PageAuditResultsPage`, `InternalLinkingPage`, `GlobalSettings`, `AppsDashboard`).
- **Operational Workflows Confirmed Functional**:
  - **WordPress Integration**: Full export package ingestion via TSE WordPress Exporter, REST API credentials auth, single-page sync, and live push.
  - **Magento 2 Integration**: Admin Bearer token authorization, category tree & CMS page import, canonical category URL resolution, and classification rules.
  - **Page Management (W3)**: Automatic page type classification (Homepage Hub rule, Structural Landing rules, Topical, Excluded), priority calculation, target phrase assignment, bulk target configuration, and natural alphanumeric sorting.
  - **Page Auditor (W4)**: Live audit execution via Page Auditor API (`page-auditor-api` on port 8005), SEO recommendations generation (Meta Title, Meta Description, H1), Alt Text batch optimization, and Fix Issue actions.
  - **Internal Linking (W5)**: Recommendation review and persistence.
  - **Shared Domain Bridge**: Domain UUID link, Master Domain shell creation, and read-only SEO context bridge.
