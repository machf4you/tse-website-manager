## Objective & Summary

Created the central **WordPress Import Rules** section within Global Settings. This page acts as the central reference and configuration baseline for how Website Manager imports and classifies pages.

### Included Sections:
1. **Automatically Exclude These Pages**: Active list of 20 auto-excluded utility/legal page rules (Privacy Policy, Cookie Policy, Terms & Conditions, Accessibility, Sitemap, XML Sitemap, RSS Feed, Feed URLs, Search Results, Author Archives, Date Archives, Attachment Pages, 404 Page, Thank You Pages, Cart, Checkout, My Account, Login, Register, Lost Password).
2. **Default Include Rule**: Clear rule specifying that all pages not matching an exclusion rule default to `Included`.
3. **WordPress Object Types**: Reference list of supported WP types (Page, Post, Category, Tag, Author, Archive, Attachment, Custom Post Type, Other).
4. **Future Import Rules**: Placeholder section designed for future settings (Automatic Page Classification, Target Phrase Rules, Priority Rules, Folder Rules, Custom Exclusion Rules, AI Classification Rules).
